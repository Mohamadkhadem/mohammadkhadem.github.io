Open-source case study

Smart Document Capture

A Flutter package suite for extracting structured data from document, receipt, and form images—with field-level confidence, manual review, and pluggable OCR engines.

View on GitHub Explore Details

Problem & Solution

Raw OCR text is not enough for production workflows. Applications need schema-aware extraction, confidence signals, and a way for people to safely correct ambiguous results. Smart Document Capture provides the layer between an image and trustworthy structured data.

Core Capabilities

Structured Capture Core

Models, schemas, locators, validators, confidence scoring, and a review widget in the core package.

Field Confidence

Confidence is kept per field, helping applications route uncertain results into a clear review flow.

Manual Review

A review interface supports correcting receipt, form, and document values rather than hiding OCR uncertainty.

Pluggable OCR

The package architecture supports multiple recognition providers behind one capture workflow.

Offline Tesseract

The companion Tesseract package works offline on Android and iOS, with Persian and English support.

hOCR Integration

Word boxes and confidence are read from hOCR output for scoring and visual review.

Architecture & Design

Flutter-first Design

A package suite designed for use inside Flutter products and application-specific schemas.

Offline by Default

The Tesseract implementation enables on-device OCR without depending on a network connection.

Extensible Roadmap

The architecture is prepared for cloud engines, document edge detection, and specialized Iranian document schemas.

Open Source

MIT licensed and structured as a core package plus focused engine implementations.

How the Tesseract package fits

smart_document_capture_tesseract is intentionally part of this same Case Study. It is the first OCR engine implementation for the core package, feeding word boxes and confidence data into the structured capture and review workflow.
