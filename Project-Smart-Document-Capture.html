Open-source case study

Smart Document Capture

A Flutter package suite for extracting structured data from document, receipt, and form images—with field-level confidence, manual review, and pluggable OCR engines.

View on GitHub ↗Explore architecture

The challenge

OCR output is only useful when it becomes trustworthy application data. This project adds the pieces around text recognition—schemas, locators, validation, confidence scoring, and a review interface—so apps can turn images into usable records.

A modular package suite

Capture core

Models, schemas, locators, validators, confidence scoring, and a review widget compose the main package.

Field-level confidence

Every extraction can retain confidence information, helping users review uncertain fields rather than treating OCR as all-or-nothing.

Manual review

A review UI supports transparent correction flows for receipts, forms, and document-derived data.

Pluggable engines

The architecture is ready for multiple OCR providers, with the first engine focused on offline capture.

Offline Tesseract add-on

smart_document_capture_tesseract uses Tesseract and hOCR for offline Android/iOS OCR, including Persian and English.

Open-source roadmap

Future directions include cloud engines, Iranian ID and bank-card schemas, and document edge detection.

Why the Tesseract package belongs here

The Tesseract package is the first OCR implementation for this system, not a separate product. It feeds word boxes and confidence data into the core package, enabling structured scoring and on-image review while keeping recognition offline.
