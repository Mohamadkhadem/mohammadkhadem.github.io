Persian Calendar Kit

A complete Flutter toolkit for Persian (Jalali / Shamsi), Gregorian, and Hijri dates—bringing date logic, localization, and customizable calendar UI into one package.

View on GitHub Explore Details

Problem & Solution

Persian-language apps often need much more than a one-off date conversion. They need correct calendar rules, localized formatting, holidays, date arithmetic, and interface components that work naturally in RTL. Persian Calendar Kit brings those requirements together in a reusable Flutter-first toolkit.

Core Capabilities

Date Conversion

Accurate Jalali, Gregorian, and Hijri conversion with ISO 8601, timestamps, Julian days, and Tehran time support.

Date Intelligence

Date arithmetic, age, periods, business days, seasons, zodiac, relative time, and duration formatting.

Formatting & Parsing

Pattern-based input and output with Persian, Arabic, and English digits, numbers, and dates written in words.

Events & Holidays

Official Iranian solar and lunar holidays, occasions, and support for custom event providers.

Calendar Widgets

Calendar, week strip, month grid, range picker, multi picker, wheel picker, and form field.

Localization

Persian, Dari, Kurdish, and English strings with RTL/LTR configuration.

Architecture & Design

Flutter Package

A reusable Dart and Flutter API that can be used with or without the included widgets.

Theme System

ThemeExtension, per-widget themes, builders, and configurable visual behavior.

Composable UI

Public component APIs make it possible to use the ready-made UI or build a custom calendar experience.

Open Source

MIT licensed for teams that need a flexible Persian-calendar foundation.

Built for real product work

The kit is designed as infrastructure, not just a date picker: teams can adopt only the date models, combine utility APIs with their own UI, or use the complete set of customizable Flutter components.
